Career loop

求职不是一次问答，而是一条连续流程

JobHunter 解决的真实问题，是信息散落在简历文件、招聘网页、面试笔记和聊天记录里，下一步总靠人临时回忆。系统让每一步产生可复用的数据，Agent 再根据这些数据推进，而不是每次从零开始。

01职业目标确认方向、城市、约束与已掌握技能。
02简历资产上传、解析、编辑、诊断并保留版本。
03JD 匹配保存真实岗位，查看证据、差距与定制建议。
04面试训练按岗位练习，沉淀回答、评分和录音复盘。
05投递看板记录机会阶段、时间线、备注和待办。
06行动复盘结合结果更新优先级，形成下一轮行动。

Contextual career agent

Agent 在业务里，不在业务旁边

每个页面都能打开同一个 Agent 工作台。当前模块、选中的简历或机会会成为可见上下文；无 API Key 时，本地策略也能连续读取看板、职业目标、行动项和训练记录，再综合给出下一步优先级。

19 个结构化工具

覆盖职业画像、简历、JD、面试、训练、机会、行动项、报告和受限网页读取；参数、所有权与超时都由服务端控制。

无 Key 也会规划

本地模式通过意图识别和确定性多工具规划完成求职诊断、机会盘点、面试准备与简历建议，不把最后一个工具结果直接当答案。

记忆与业务闭环

工作、语义、情景和任务记忆分别保存会话、确认事实、历史结果与缺失信息；建议可回到简历、机会、行动项或报告。

Human approval boundary

能建议，也能推进；最后决定权在用户

读取和分析可以直接执行。所有 Agent 写入都走“提议 → 预览 → 单次确认”链路，并记录状态与审计信息。risk_level 会随提议展示并由服务端校验；当前界面没有额外二次确认。

Read

先理解上下文

工具只读取当前本地用户有权访问的数据，并把必要结果返回给 Agent。

Propose

展示影响范围

写操作先生成提议，显示对象、字段变化、理由与风险，不把模型输出直接写入数据库。

Confirm

单次确认后执行

服务端再次校验所有权、状态、有效期和幂等键；过期或已执行提议不能重复执行。

能力边界：JobHunter 不会自动投递，不会替你向招聘方发送消息，也不承诺获得 Offer。它帮助你组织证据、练习表达和管理行动。

Overview

先知道现在在哪里

首页把分散记录汇成今日求职作战台。准备度包含数据限制条件和下一步，不把一个分数包装成确定结论。

  • 职业目标与短板可见
  • 行动入口回到真实模块
  • 无数据时提供明确空状态

Resume lab

让简历成为可维护资产

支持原文件、解析文本、编辑版本和面向 JD 的定制草稿。Agent 可读取差距并提出修改任务，但不会静默覆盖主简历。

Interview studio

训练结果能被下一次使用

文字流程不依赖浏览器语音能力。支持时可录音与回放；不支持时保留文字回答和音频文件上传，历史回答继续用于复练。

Opportunity pipeline

机会推进有迹可循

把岗位从准备、已投递、面试到结束的变化记录下来。Agent 能建议跟进日期或阶段更新，实际写入仍需要确认。

Opportunity workspace

围绕一个岗位组织全部准备

机会详情按概览、JD 与匹配、简历版本、面试准备和时间线组织，避免“看板有岗位，准备材料却找不到”的断层。

Architecture

Agent Runtime、工具与领域数据分层

当前没有引入 LangChain 或 LangGraph，而是基于 Flask、SQLite 和 JSON Schema 实现轻量 Agent Runtime。它已具备策略切换、工具循环、任务预算、分层记忆和审计边界，避免为已有能力增加重复框架层。

一条可替换的调用链

页面 / Agent 工作台呈现数据、上下文标签、提议差异与执行结果。
Flask HTTP解析请求、固定本地用户、序列化响应。
Agent Runtime + 工具19 个结构化工具、远程模型/本地策略切换、任务续接、时限与次数预算。
领域服务简历、机会、面试、准备度和行动提议共用一致规则。
SQLite本地持久化业务数据、Agent 记忆、运行记录与审计状态。

分层记忆，各自解决一个问题

工作记忆

保留当前会话窗口和摘要，让一次任务在有限上下文中继续。

语义记忆

保存目标岗位、城市、约束等长期画像；候选推断需确认后才能影响关键决策。

情景记忆

记录已完成任务的结果摘要，帮助后续复盘，不保存模型私有思维链。

任务记忆

保存行动类型、缺失槽位和状态，支持追问后续接与可观察进度。

工具安全：服务端注入当前用户标识；参数经过 JSON Schema 校验；网页工具限制超时、响应大小并拒绝本机和内网地址。工具事件和写入结果进入审计记录。

Run locally

双击 start.bat，从本机开始

Windows 用户无需先理解 Flask 或命令行。启动器会定位项目目录、选择可用 Python、检查依赖和端口、等待健康检查通过，再用系统默认浏览器打开应用。

小白启动路径

  1. 下载或克隆项目。
  2. 在项目根目录双击 start.bat。
  3. 第一次运行按提示安装依赖；之后可直接启动。
  4. 使用结束后在启动窗口按 Ctrl+C 停止本项目服务。

Local mode & compatibility

无需 API Key，也能完成基础闭环

没有配置远程模型时，界面会明确显示“本地规则模式”。确定性策略能识别常见自然问法，连续调用多个业务工具并综合行动优先级，也能完成简历诊断、机会盘点和面试准备；它不会伪装成大模型推理。

Microsoft Edge核心文字流程与响应式界面验证。
Google Chrome核心流程、桌面/平板/移动视口验证。
Mozilla Firefox核心文字流程；语音与录音按能力降级。

本版本验收证据：Python 288/288、Node 40/40；浏览器矩阵 7 PASS / 2 Firefox SKIP（本机缺少 Firefox 可执行文件，SKIP 不是通过）。

隐私边界：当前版本定位为本地单用户应用，SQLite 数据库、上传文件、导出文件、日志和 API Key 不提交到 Git。它不是带登录、云同步和多租户隔离的公开服务；如需公网部署，必须另行补齐认证、授权和加密设计。
